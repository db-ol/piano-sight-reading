# 五级视奏网站方案

更新日期：２０２６年１０月２５日。

## 目标与边界

在当前仓库实现中文静态网站，以 iPhone 竖屏为主，电脑也能使用。不需要构建和服务器端服务，沿用隔壁 `../scales` 的传统浏览器脚本组织、Web Audio 合成音色、service worker 和 `node --test`。外部发布另行确认。

官方参数与出处见 [research.md](research.md)。官方没有规定绝对音域、固定速度和每种节奏出现次数。本项目会公开自己的生成范围，不把教学选择称为官方规定。原创新曲不复制官方例题。

## 页面与流程

首页是练习工作台，上方显示本次调性、拍号和难度，下方是清楚的大谱表。手机按一小节或两小节一行自动排版，允许纵向滚动。提供练习、模拟考试、练习记录与规则说明。

练习可换题、固定调性或拍号、选择五级范围内的下限、中间和上限、慢速听示范、开节拍器，以及随时开始录音。三个难度是本站教学分档。每首曲子由动机、回答、和声进行和终止式构成。

模拟考试先准备输入设备，随后显示新谱并开始３０秒倒计时。准备时可以试弹部分或全部，准备音不参与分析。时间到后显示开始提示并记录正式弹奏。用户点结束后分析，不根据一段静音擅自认定已经弹完。进入后台时中止本次录制并明确提示，防止生成误导成绩。

反馈按音符或位置标记错音、漏音、节奏偏差和停顿。额外音显示在对应位置及文字列表中。颜色配合符号与逐项文字，避免只依靠颜色。整体匀速较慢和不稳定拍子分开说明。不会模拟官方数字分数或声称判断了音色、乐句与全部音乐表现。

记录保存在本机 localStorage，包含题目参数、输入来源、统计和日期。录音只在本次页面内存中保留，可回听和下载，不上传。历史中的自动分析与自评分开标明，提供清空入口。

## 技术选择

使用固定版本 VexFlow 的本地 SVG 绘谱库。每个和弦的音头能独立着色，按屏宽重新排版。字体、依赖和模型保存在仓库中，不依赖运行时 CDN。

输入分为麦克风、Web MIDI 和无设备自评。Safari 没有原生 Web MIDI，因此通过能力检测给出可用路径，不向 iPhone 用户展示虚假的连接成功状态。支持 Web MIDI 的电脑浏览器可直接记录 note on 与 note off。

麦克风请求关闭回声消除、降噪、自动增益，并读取浏览器实际采样率与约束结果。先录音，结束后用 Basic Pitch 与 TensorFlow.js 在本机做复调转录。模型按需加载并提供离线缓存入口，失败时仍可回听与自评。不能承诺手机实时识别，也不能把模型激活值称为校准过的正确概率。

对齐先合并短时间内的和弦起音，再用单调序列匹配音集，估计整体速度并限制时间伸缩。判别遗漏、替代、额外音与局部时间偏差，保留停顿。对麦克风结果统一使用待核对的措辞，低置信音标为不确定，避免直接给出确定扣分。

播放复用隔壁网站的音频恢复逻辑。页面隐藏或系统中断后，下一次点击重建 AudioContext。录音也在重新点击后新建采集上下文，不依赖可能已经失效的旧实例。

## 验证

用 Node 内置测试检查全部调性、拍号与三个难度，包括小节时值、音域、合法时值、调号音名、声部与和弦上限、种子复现与终止。对齐测试采用合成音符数据，包括全对、错一个音、漏音、多音、整体放慢、节奏偏差、中途停顿和识别不确定。

用无头浏览器检查３９０×８４４、３７５×６６７和电脑尺寸，分别截图浅色与深色。检查横向溢出、谱面完整、交互、离线重载和错误日志。软件模拟不能证明真 iPhone 的麦克风、蓝牙或锁屏恢复已经验证，交付时逐项说明实测边界。

## 待决定与未确定事项

没有阻塞本地实现的问题。默认使用麦克风，保留 MIDI 与自评。

需要你决定的偏好：常用原声钢琴还是电钢琴？是否愿意接电脑 MIDI？未收到回复前仍按 iPhone 麦克风优先设计。

官方未公布统一的考官逐字台词和绝对音域。本项目采用中文流程提示与保守手位，不伪造官方原话。是否需要与老师指定的练习音域或措辞一致？如果需要，可以之后提供老师的要求再调整，当前不阻塞练习。
