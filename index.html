    五级视奏

    约８至１２小节。拍号包括２／４、３／４、４／４、３／８、６／８。双手演奏，每手和弦最多两个音。

    大调包括Ｃ、Ｇ、Ｆ、Ｄ、Ａ、降Ｂ、降Ｅ、Ｅ、降Ａ。小调包括ｄ、ａ、ｅ、ｇ、ｂ、升ｆ、ｃ。

    七级视奏

    约１６至２０小节。范围包括升 C 小调、F 小调、复拍子、不规则拍子和速度变化。遇到八分之七拍，先看符杠怎样把七个八分音符分组。

    八级视奏

    大纲给出的长度约为一页印刷谱。范围增加 B 大调、降 D 大调和八分之十二拍。可以先认三音和弦的手形，再找速度变化的位置。手机上的屏数随设备大小而变。

    模拟考试准备

    三个级别都有３０秒准备时间，可以试弹任意部分。先看调号、拍号、起始手位和速度标记。

    反馈怎么读

    MIDI 直接记录键盘事件。麦克风需要从声音中推测音符，踏板、混响、和弦和环境噪声都可能造成误判。麦克风结果一律待核对，不等于你真的弹错。

    均匀放慢不等于节奏不稳。停顿与局部节奏偏差会单独提示。全无输入或识别失败时不会生成“全错”的成绩。

    设备与离线

    要使用电钢琴，请连接支持 Web MIDI 的电脑浏览器。浏览器没有 MIDI 接口时，可以使用麦克风或选择自评。

    麦克风需要 HTTPS 或本机 localhost，以及你的授权。请把手机放稳，尽量减少环境声音。录音时示范与节拍器自动关闭，避免被一起录入。

    首次联网打开后可缓存网站。转录模型需要另行下载一次，所有处理都在本机。浏览器可能回收离线数据和练习历史。
