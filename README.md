# 五级视奏

面向成年学琴者的中文钢琴视奏练习网站，以 iPhone 竖屏为主，也支持电脑。依据 ABRSM Piano Practical Grade 5 的累计视奏参数生成原创双手乐谱，提供练习、模拟考试、录音反馈与本机历史。

纯静态 HTML、CSS 和 JavaScript，无需构建、账号或后端服务。组织方式、`node --test` 测试和音频恢复逻辑参考相邻的 `../scales` 项目。

## 开始使用

在项目目录运行：

```sh
python3 -m http.server 8765
```

电脑打开 [本地网站](http://localhost:8765)。不要直接双击 `index.html`，service worker 和麦克风需要安全上下文。

手机麦克风需要 HTTPS。用 iPhone 打开电脑的普通局域网 HTTP 地址，不能获得与电脑 localhost 相同的麦克风权限。网站正式发布后可通过 Safari 的“添加到主屏幕”使用。

## 功能

- **原创出题**：覆盖五级累计的１６个调和５种拍号。可固定调性、拍号并选３档练习难度。乐句有动机复现、回答、半终止和属到主终止，小调终止使用升导音。部分上限题包含弱起、切分、十六分音符、临时记号和四声部和弦。
- **清楚读谱**：双手大谱表随手机宽度重排，支持深色模式和“专注看谱”。单个和弦音头可以分别着色。
- **自由练习**：听合成钢琴示范，选择原速、８０％或６０％速度，开节拍器，或不录音自由弹奏。
- **模拟考试**：先准备输入，再换一张新谱并倒计时３０秒。准备时可试弹部分或全部，试弹不计入正式反馈。时间到后开始记录，弹完手动结束。
- **反馈**：标记错音、漏音、多弹音、节奏偏差和停顿，区分整体放慢与局部不稳定。麦克风结果标为疑似或待核对，支持回听和下载本次 WAV 录音。
- **历史与自评**：按拍子、音高和音乐细节复盘，查看本机记录与常见问题。MIDI、麦克风和自评分别注明来源，可清空历史。

五级下限、中段和上限是本站的教学分档。默认速度和保守音域也是练习设计，不是官方公布的固定边界。当前生成器使用有限的动机与调性和声结构，不代表考试中的全部音乐风格。

## 输入方式与准确性

麦克风使用本地 Basic Pitch 与 TensorFlow.js，在录完后分析双手和弦，不上传音频。它是实验功能，踏板、混响、弱音、泛音和环境噪声都可能带来误判，没有经过真实钢琴录音标注验证的准确率数字。模型激活值也不是“弹错概率”。识别失败时仍可回听并自评。

网页会请求关闭回声消除、降噪和自动增益，读取浏览器实际返回的设置与采样率。录音期间关闭示范和节拍器，避免把网页声音录入。单次录音最多三分钟，分析时请保持页面在前台。

截至２０２６年１０月的调研，iPhone Safari 和 macOS Safari 不支持原生 Web MIDI。电钢琴可尝试连接支持 Web MIDI 的电脑 Chrome、Edge 等浏览器。网页按实际能力检测接口，不会把未连接的设备显示为连接成功。MIDI 记录按键事件，不录制钢琴声音。

播放沿用 `../scales/js/audio.js` 的处理方式：锁屏、进入后台或音频中断后标记旧上下文失效，返回后的第一次点击重建 AudioContext。进入后台会停止本次录音或 MIDI 会话，并明确提示重新开始。

这些恢复路径已纳入软件测试，但**没有在真实 iPhone、真实钢琴麦克风或物理 MIDI 设备上完成验证**。桌面浏览器与模拟输入测试不能替代真机验证。详见 [验证记录](docs/verification.md)。

## 离线使用与数据

1. 首次联网打开网站，等待页面底部显示离线资源已准备。
2. 打开“说明”，点击“准备离线识别模型”，等待缓存完成。
3. 再断网重开，检查乐谱、示范和模型仍可用。模型缓存完成前，离线时仍可读谱、播放示范与自评，但不能保证能加载录音识别。

依赖、字体和模型都放在本仓库，运行时不依赖 CDN。浏览器可能回收缓存，因此“已缓存”不表示永久保留。代码更新时需同步 `sw.js` 文件列表并修改缓存版本。

历史使用本机 `localStorage`，最多保留最近１００条。录音只在当前页面内存中保留，不随历史永久保存，需要时点击“保存录音”。清理网站数据会删除记录与离线资源。

## 测试

单元测试不需要安装测试框架：

```sh
node --test tests/*.test.js
```

测试覆盖所有调性、拍号和难度组合的小节时值、音名拼写、音域、双手分离、合法时值、弱起、终止式，以及合成弹奏的全对、错音、漏音、多音、变速、节奏偏差与停顿。另有音频恢复、录音生命周期、MIDI、重采样和模型测试。

已准备无头 Chrome 检查脚本。它需要本机 Chrome 和可用的 `playwright-core`，不属于网站运行依赖。启动上述本地服务后运行：

```sh
node tools/browser-check.cjs
node tools/session-check.cjs
node tools/feedback-check.cjs
```

可通过 `PLAYWRIGHT_MODULE` 指定已有模块的绝对路径，通过 `PREVIEW_URL` 指定预览地址。三个脚本分别检查手机布局与离线、模拟考试与权限流程，以及单音着色和反馈。布局包括３９０×８４４、３７５×６６７和电脑尺寸的浅色与深色，截图与检查结果保存在 `artifacts/`。最终执行结果与验证范围以 [验证记录](docs/verification.md) 为准。

## 文件组织

| 文件 | 用途 |
| --- | --- |
| `index.html`、`css/style.css` | 中文界面和手机布局 |
| `js/generator.js`、`js/score.js` | 原创出题和 SVG 大谱表 |
| `js/audio.js` | 示范、节拍器和音频恢复 |
| `js/input.js`、`js/recorder-worklet.js` | 麦克风 PCM 采集、WAV 与 MIDI |
| `js/transcribe.js`、`js/alignment.js` | 本机复调转录、乐谱对齐和练习反馈 |
| `js/storage.js`、`js/app.js` | 本机记录和页面流程 |
| `sw.js`、`manifest.webmanifest`、`icons/` | 离线缓存和主屏幕入口 |
| `vendor/`、`fonts/` | 固定版本依赖、模型、字体和相应许可证 |
| `tests/`、`tools/browser-check.cjs` | 单元测试和浏览器检查 |

调研和设计依据见 [完整调研](docs/research.md)、[功能与技术方案](docs/plan.md)、[依赖说明](vendor/DEPENDENCIES.md)。

## 考试规则与发布

两版官方大纲的五级视奏要求相同。准备时间为３０秒，可试弹部分或全部。视奏满分２１分，及格档从１４分开始。网站的反馈仅供练习参考，不给出 ABRSM 官方分数，也不声称能完整评价音色、乐句或演奏表现。逐项来源网址与印刷页码均见 [调研文档](docs/research.md)。本项目不是 ABRSM 官方产品，与 ABRSM 没有关联。

建议发布仓库为 `github.com/db-ol/grade5-sight-reading`，GitHub Pages 地址为 `https://db-ol.github.io/grade5-sight-reading/`。当前只是建议目标，尚未创建远程仓库、推送或发布。外部发布需先向 Aaron 展示完整待发布内容与目标，并等待明确批准。
